1. Introduzione alla Piattaforma

Enterprise AI Chat e una piattaforma aziendale di intelligenza artificiale conversazionale che consente di interagire con i piu avanzati modelli AI del mercato attraverso un'interfaccia unificata, sicura e conforme alle normative europee sull'AI (AI Act).

Cosa puoi fare con la piattaforma
  • Conversare con AI - Chat interattiva con modelli di OpenAI (GPT-4, GPT-4o), Anthropic (Claude), Google (Gemini) e modelli locali (Ollama)
  • Allegare documenti - Carica PDF, Word, Excel, PowerPoint, immagini e file di codice per farli analizzare dall'AI
  • Generare documenti - Esporta le conversazioni o genera nuovi documenti in Word, Excel, PowerPoint e PDF
  • Gestire progetti - Organizza il lavoro con bacheche Kanban, task, priorita e assegnazioni
  • Usare agenti autonomi - Configura agenti AI che eseguono compiti complessi in autonomia con accesso a tool e codice
  • Memoria persistente - L'AI ricorda le tue preferenze, decisioni e pattern tra una sessione e l'altra
  • Programmazione attivita - Pianifica messaggi ed azioni automatiche con lo scheduler

Architettura del Sistema

La piattaforma e composta da diversi componenti che lavorano insieme:

Frontend (React)

Interfaccia web moderna costruita con React 18, Vite e Tailwind CSS. Supporta streaming in tempo reale, dark mode e design responsive.

Backend (Fastify)

Server API costruito con Fastify 5 e TypeScript. Gestisce autenticazione, routing AI, elaborazione documenti, memoria e 20+ moduli funzionali.

Database (MariaDB + Redis)

MariaDB per la persistenza dei dati (conversazioni, utenti, configurazioni). Redis per caching delle sessioni e code di messaggi.

Infrastruttura (Kubernetes)

Deploy su MicroK8s con replica multiple, bilanciamento del carico, tunnel Cloudflare per accesso sicuro e certificati TLS.

2. Accesso e Autenticazione

Login

Accedi alla piattaforma inserendo le tue credenziali:

1
Naviga all'indirizzo della piattaforma (es: https://plane.lushlolli.com)
2
Inserisci il tuo indirizzo email e la password
3
Se hai abilitato l'MFA (Multi-Factor Authentication), inserisci il codice a 6 cifre dalla tua app di autenticazione
4
Al primo accesso, accetta i termini di utilizzo, l'informativa sulla privacy e il consenso all'elaborazione AI
Suggerimento

La sessione rimane attiva per 7 giorni. Se accedi da un nuovo dispositivo, la sessione precedente viene automaticamente terminata per sicurezza (sessione singola).

Autenticazione a Due Fattori (MFA)

Per proteggere il tuo account, puoi abilitare l'autenticazione TOTP:

  1. Vai su Impostazioni (icona ingranaggio nella sidebar)
  2. Nella sezione Sicurezza & MFA, clicca su "Configura MFA"
  3. Scansiona il codice QR con un'app come Google Authenticator o Microsoft Authenticator
  4. Inserisci il codice a 6 cifre per verificare la configurazione
  5. Da questo momento, ad ogni login ti verra richiesto il codice MFA
Importante

Conserva la chiave segreta in un luogo sicuro. Se perdi l'accesso all'app di autenticazione, dovrai contattare un amministratore per il reset.

3. Chat con l'AI

La pagina principale della piattaforma e l'interfaccia di chat, dove puoi conversare con i modelli AI disponibili.

Interfaccia di Chat

L'interfaccia e divisa in tre aree principali:

Sidebar (Barra Laterale)
  • Nuova Chat - Pulsante "+" per avviare una nuova conversazione
  • Elenco Conversazioni - Cronologia di tutte le tue chat, ordinate per data di ultimo aggiornamento
  • Ricerca - Cerca tra le conversazioni per titolo
  • Archivio - Visualizza/ripristina conversazioni archiviate
  • Gestione - Archivia o elimina tutte le conversazioni
  • Download VS Code Extension - Scarica l'estensione per l'editor
  • Guide - Scarica le guide utente e amministratore
  • Menu Utente - Nome, email, link a impostazioni e logout
Area Chat Centrale
  • Selettore Modello - Scegli quale modello AI usare (nell'header)
  • Messaggi - Visualizzazione della conversazione con rendering Markdown, evidenziazione sintassi codice, e formattazione avanzata
  • Campo di Input - Area testuale per scrivere i messaggi con supporto multilinea
  • Allegati - Pulsante per allegare file (clip)
  • Invio - Pulsante di invio del messaggio
Pannelli Laterali Destro
  • Pannello Memoria - Mostra le osservazioni della memoria personale
  • Memoria Vettoriale - Mostra i risultati della ricerca semantica (episodica, dichiarativa, procedurale)

Come Inviare un Messaggio

1
Seleziona il modello AI desiderato dal menu a tendina nell'header (es: GPT-4o, Claude 3.5 Sonnet, Gemini 2.0 Flash)
2
Scrivi il tuo messaggio nell'area di input in basso
3
(Opzionale) Allega file cliccando sull'icona graffetta
4
Premi Invio o clicca il pulsante di invio
5
La risposta dell'AI appare in streaming (in tempo reale, parola per parola)

Funzionalita dei Messaggi

Ogni messaggio dell'AI supporta diverse funzionalita:

  • Rendering Markdown - Titoli, elenchi, grassetto, corsivo, tabelle
  • Codice con Syntax Highlighting - Blocchi di codice colorati per tutti i linguaggi principali
  • Thinking (Ragionamento Esteso) - Alcuni modelli (Claude) mostrano il processo di ragionamento prima della risposta, espandibile/comprimibile
  • Feedback - Pulsanti pollice su/giu per valutare la qualita della risposta
  • Etichetta AI - Ogni risposta e contrassegnata come "Generato dall'AI" per conformita AI Act
  • Avviso Argomenti Sensibili - Se l'AI rileva temi sensibili (salute, legale, finanza) mostra un avviso di disclaimer

Prompt di Sistema

Puoi opzionalmente impostare un system prompt per guidare il comportamento dell'AI in una conversazione specifica. Questo e utile per:

  • Definire il ruolo dell'AI (es: "Sei un esperto di diritto italiano")
  • Impostare il formato delle risposte (es: "Rispondi sempre in italiano con elenchi puntati")
  • Fornire contesto specifico per un progetto

8. Sistema di Memoria

Il sistema di memoria consente all'AI di ricordare informazioni tra le sessioni, personalizzando le risposte in base alla tua esperienza.

Tipi di Memoria

TipoDescrizioneEsempio
InsightIntuizioni e scoperte"L'utente preferisce Python per data science"
DecisioneDecisioni prese"Si e scelto di usare PostgreSQL come database"
PatternSchemi ricorrenti"L'utente chiede spesso informazioni su REST API"

Memoria Vettoriale (RAG)

Oltre alla memoria testuale, il sistema usa un motore di ricerca semantica vettoriale con tre collezioni:

  • Episodica - Ricordi di conversazioni passate e interazioni
  • Dichiarativa - Conoscenze e fatti appresi
  • Procedurale - Procedure e metodi da seguire

Queste memorie vengono automaticamente iniettate nel contesto delle nuove conversazioni, consentendo all'AI di richiamare informazioni rilevanti senza doverle riscrivere.

Working Memory (Memoria di Lavoro)

Ogni conversazione ha una "memoria di lavoro" temporanea che tiene traccia del contesto della sessione corrente, ottimizzando i token utilizzati.

Gestione Memoria

Nelle impostazioni della memoria puoi:

  • Abilitare/disabilitare la cattura automatica
  • Attivare/disattivare l'iniezione nel contesto
  • Impostare il numero massimo di osservazioni
  • Definire la soglia di importanza minima
  • Configurare i giorni di ritenzione

9. Progetti e Kanban

La piattaforma include un sistema completo di gestione progetti con bacheche Kanban.

Creare un Progetto

1
Vai alla pagina Progetti dal menu di navigazione
2
Clicca su "Nuovo Progetto"
3
Inserisci nome, descrizione e colore del progetto
4
Il progetto viene creato con una bacheca Kanban predefinita

Bacheca Kanban

Ogni progetto ha una o piu bacheche Kanban con colonne personalizzabili:

  • Colonne Standard - Backlog, Da Fare, In Corso, Revisione, Completato
  • Colonne Personalizzate - Aggiungi, rinomina o elimina colonne
  • Limiti WIP - Imposta limiti massimi di card per colonna

Gestione Card (Task)

Le card rappresentano i task da completare:

  • Titolo e Descrizione - Descrivi il task in dettaglio
  • Priorita - Bassa, Media, Alta, Urgente (con colori distinti)
  • Scadenza - Imposta una data di scadenza
  • Assegnazione - Assegna il task a un membro del progetto
  • Etichette - Aggiungi tag colorati per categorizzare
  • Drag & Drop - Sposta le card tra le colonne trascinandole
  • Registro Attivita - Ogni modifica viene tracciata automaticamente

Condivisione Progetti

Puoi condividere i tuoi progetti con altri utenti della piattaforma, permettendo la collaborazione sui task.

10. Agenti AI Autonomi (Auto-Claude)

Il sistema di agenti autonomi permette di delegare compiti complessi all'AI, che li eseguira in autonomia utilizzando tool, terminali e accesso al codice.

Accesso

Vai alla pagina Auto-Claude dal menu di navigazione per accedere al dashboard degli agenti.

Dashboard Orchestratore

Il dashboard mostra:

  • Slot Terminali - 12 slot disponibili per esecuzioni parallele
  • Sessioni Attive - Numero di agenti in esecuzione
  • Tasso di Successo - Percentuale di completamento con successo
  • Durata Media - Tempo medio di esecuzione

Creare una Sessione Agente

1
Clicca "Nuova Sessione"
2
Configura la sessione:
  • Nome - Nome descrittivo per la sessione
  • Task - Descrizione del compito da svolgere
  • Modello - Modello AI da utilizzare
  • Template - (Opzionale) Scegli un template predefinito
  • Iterazioni Massime - Limite di cicli
  • Timeout - Tempo massimo in secondi
  • Auto-commit - Commit automatico delle modifiche al codice
  • Esegui Test - Esecuzione automatica dei test
  • Crea Worktree - Isola le modifiche in un branch separato
3
Clicca "Avvia" per iniziare l'esecuzione

Monitoraggio

  • Log in Tempo Reale - Visualizza i log dell'agente colorati per tipo (info, warning, errore)
  • Stato - Pending, Initializing, Running, Paused, Completed, Failed, Cancelled
  • Pausa/Ripresa - Metti in pausa e riprendi l'esecuzione
  • Cancellazione - Annulla l'esecuzione in corso

Template Agente

I template predefiniti accelerano la creazione di sessioni per scenari comuni:

  • Development Sviluppo di nuove funzionalita
  • Testing Scrittura e esecuzione test
  • Documentation Generazione documentazione
  • Research Ricerca e analisi
  • Automation Automazione di processi

11. Parlant - Framework Agenti

Parlant e un framework Python per la creazione di agenti AI con comportamento guidato da linee guida.

Concetti Chiave

  • Agenti - Entita AI con personalita e competenze definite
  • Guidelines (Linee Guida) - Regole condizione-azione che governano il comportamento (es: "Quando l'utente chiede di X, allora rispondi con Y")
  • Sessioni - Contesti di conversazione con l'agente
  • Tool - Strumenti API che l'agente puo utilizzare

Come Funziona

  1. Crea un agente con nome e descrizione
  2. Definisci le linee guida come coppie condizione/azione
  3. Avvia una sessione di conversazione
  4. L'agente applica automaticamente le linee guida pertinenti

Funzionalita

  • Chat nell'Editor - Apri una finestra di chat AI direttamente in VS Code
