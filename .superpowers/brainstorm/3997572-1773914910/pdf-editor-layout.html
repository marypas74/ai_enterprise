Dove posizionare l'editor PDF nella chat?

Scegli il layout che preferisci per l'editor PDF all'interno della conversazione

A

Pannello Inline (sotto il messaggio)

L'editor appare direttamente nella chat, sotto il messaggio dell'AI, come un blocco espandibile. La chat continua sopra/sotto normalmente.

AI: Ecco il PDF pronto per la modifica. Ho evidenziato la sezione 3...
Testo Evidenzia Note Firma Disegna
📄 Pagina PDF renderizzata qui (450×600)
Pagina 1 di 5
← → Salva
Tu: Grazie, aggiungo la firma...

Pro

  • Tutto nel flusso della chat
  • Contesto conversazionale visibile

Contro

  • Spazio limitato per l'editor
  • Puo rendere la chat molto lunga
B

Pannello Laterale (slide-in da destra)

L'editor si apre come un pannello che scorre dal lato destro, affiancato alla chat. La chat rimane visibile e utilizzabile.

AI: Ho aperto l'editor PDF...
Tu: Perfetto, modifico...
Area input chat
Editor PDF ✕ Chiudi
Testo Evidenzia Note Firma
📄 PDF Editor
Pag 1/5 Salva

Pro

  • Piu spazio per editare il PDF
  • Chat e editor affiancati
  • Pattern UI comune (Slack, Teams)

Contro

  • Riduce lo spazio della chat
  • Su mobile potrebbe non funzionare bene
C

Modale / Overlay a schermo intero

L'editor si apre come un overlay che copre la chat, con un pulsante per tornare alla conversazione. Massimo spazio di lavoro.

Editor PDF contratto_2026.pdf
Salva ← Torna alla Chat
Seleziona Testo Evidenzia Note Disegna Immagine Firma Form Timbro Oscura
📄 PDF a schermo intero — massimo spazio di lavoro
◀ Pagina 1 di 5 ▶ Zoom: 100%

Pro

  • Massimo spazio per editare
  • Esperienza editor dedicata
  • Funziona bene anche su mobile

Contro

  • Si perde il contesto della chat
  • Bisogna chiudere per tornare alla conversazione
