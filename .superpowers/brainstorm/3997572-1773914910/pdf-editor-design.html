Componenti del Sistema

FRONTEND
  • PDFEditorPanel — pannello laterale slide-in
  • TipTap editor — rich text editing WYSIWYG
  • usePDFEditor hook — stato editor
  • Trigger detection — pulsante + AI marker
BACKEND
  • POST /pdf-editor/convert — PDF → HTML
  • POST /pdf-editor/save — HTML → PDF
  • LibreOffice CLI — conversione formati
  • Temp file management — cleanup

Trigger dall'AI

Quando l'AI rileva una richiesta di editing PDF, include un marker HTML nel messaggio:

<!-- pdf_editor:attachmentId=168,filename=contratto.pdf -->

Il frontend rileva questo marker e apre automaticamente il pannello editor. L'utente puo anche aprirlo manualmente con il pulsante "Modifica" sull'allegato PDF.
